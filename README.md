#  Product Review System

A Full-Stack Product Review Platform where users can explore products, write reviews with images, and rate items .

Built using modern full-stack technologies with secure authentication and a clean, responsive UI.

##  Tech Stack

###  Backend
- Spring Boot  
- Spring Security (JWT Authentication + Refresh Token)  
- JPA / Hibernate  
- MySQL  
- REST APIs  

###  Frontend
- React (Vite)  
- Tailwind CSS  
- Axios  
- React Router  

---

##  Features
- View all products  
- Read reviews  
- View product ratings  
- Register & Login securely (JWT-based authentication)  
- Add product reviews  
- Upload review images  
- Give ratings  
- Edit/Delete their own reviews  
- Add new products  
- Update product details  
- Delete products  
- Manage platform content  

---

##  Key Features

- Secure Authentication (Access + Refresh Tokens)
- Review with Image Upload
- Rating System
- Fully Responsive UI
- RESTful API Architecture
- Clean layered backend (Controller → Service → Repository)
- Duplicate Review Prevention
- Proper Exception Handling
